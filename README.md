# Doublets — этап 1: русский словарь и движок

Python 3.10+, без сторонних зависимостей для базового импорта и BFS.

## Правила
- Существительные (NOUN), именительный падеж (nomn), единственное число (sing).
- 3–6 букв; только кириллица а-я и ё; ё не нормализуется в е.
- Каждым ходом заменяется ровно одна буква; длина слова неизменна.

## Источник словаря
Скачайте OpenCorpora XML самостоятельно с https://opencorpora.org/?page=downloads и проверьте актуальные условия лицензирования/атрибуции перед распространением. Исходный словарь **не включён** в архив. Программа не заявляет, что любая автоматически извлечённая форма общеупотребительна: потребуется ручной или частотный фильтр. Некоторые неоднозначные формы будут включены, если у них есть подходящий разбор.

## Команды
```bash
python cli.py build data/source/dict.opcorpora.xml --out data/export/words.json
python cli.py stats
python cli.py solve кот кит
python cli.py generate --min-moves 2 --max-moves 6 --seed 42
python -m unittest discover -s tests -v
```

## Структура
- `doublets/dictionary.py` — потоковый импорт морфологического XML.
- `doublets/engine.py` — индекс соседей, BFS, валидация ходов, случайная пара.
- `cli.py` — команды для сборки и проверки.
- `tests/` — автоматические тесты.
- `data/source/` — локальный исходный XML (не включён).
- `data/export/` — экспортируемый JSON (после сборки).

## Следующие задачи перед UI
1. Проверить полноту OpenCorpora и лицензии на конкретную версию выгрузки.
2. Добавить частотный фильтр, список исключений и белый список.
3. Генерировать офлайн-каталог уровней с метриками и исключать неинтересные пары.
4. Добавить интеграционные тесты на полном словаре и отчёт по компонентам связности.
5. Закрепить версию и контрольную сумму словаря для воспроизводимости.

`random_level` — прототип с ограниченным числом попыток, а не гарантированно равномерный выбор всех возможных пар. В реальной игре рекомендуется подготовленный каталог уровней.
