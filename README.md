# Doublets — русский словарь и игровой движок

Первый этап Doublets: существительные в именительном падеже единственного числа, длина **3–6 букв**, буквы **Е** и **Ё** различаются. Каждый ход заменяет ровно одну букву. Python 3.10+.

## Быстрый запуск в PyCharm / Windows

В PyCharm выбери проектный Python и открой **Terminal**:

```powershell
python -m pip install -r requirements.txt
python cli.py stats
python cli.py analyze
python cli.py solve кот кит
python cli.py generate --min-moves 3 --max-moves 6 --seed 42
python -m unittest discover -s tests -v
```

В репозитории есть `data/export/words.json` в старом формате JSON-массива. CLI теперь читает и массив, и объект `{"words": [...], "rules": ...}`.

## Пересоздать словарь без сайта OpenCorpora

```powershell
python cli.py build-pymorphy
```

Для импорта используются установленные `pymorphy3` и `pymorphy3-dicts-ru`. Экспорт записывается в `data/export/words.json` в версионированном формате с метаданными. Существующий словарь будет перезаписан, поэтому при необходимости сохраните его копию. Альтернативный XML-импорт остаётся доступен:

```powershell
python cli.py build data/source/dict.opcorpora.xml
```

## Качество словаря

Результат первого анализа: **12 397 слов**, из которых 638 трёхбуквенных, 1939 четырёхбуквенных, 4019 пятибуквенных и 5801 шестибуквенное (из пользовательского запуска; не автоматически перепроверено CI).

Для анализа связности:

```powershell
python cli.py analyze
```

Для сохранения очищенной расширенной базы и кандидатов в основной словарь:

```powershell
python cli.py quality
```

По умолчанию `words_core.json` будет пуст: **частотный источник пока не подключён**, и мы не объявляем слова общеупотребительными без проверки. `words_extended.json` будет содержать все исходные слова кроме исключённых вручную.

Заполни `data/quality/excluded_words.txt`, по одному слову на строку. При наличии **лицензионно допустимого частотного файла** формата `слово число`:

```powershell
python cli.py quality --frequency data/quality/frequency_ru.txt --min-frequency 5
```

Создаются:

- `data/processed/words_core.json` — кандидаты в общеупотребительные слова по порогу частотности;
- `data/processed/words_extended.json` — расширенный список без ручных исключений;
- `data/processed/words_excluded.json` — реально исключённые слова;
- `data/processed/quality_report.json` — числа слов, рёбра, компоненты, изолированные слова, SHA256.

Частотный порог зависит от шкалы источника; это не универсальное значение. Частотность не гарантирует, что слово понятно игроку. Основной словарь требует редакторской проверки.

## Файлы

- `doublets/engine.py` — индекс соседей, BFS, проверка ходов и прототип генератора;
- `doublets/dictionary.py` — старый OpenCorpora XML importer и единая схема экспорта;
- `build_pymorphy_dictionary.py` — импорт из установленного pymorphy3;
- `doublets/dictionary_quality.py` — загрузка старого/нового JSON, фильтрация, графовая статистика;
- `cli.py` — консольный интерфейс;
- `tests/` — unit-тесты.

## Ограничения и дальнейшие задачи

1. Текущий словарь **не проходит редакторскую проверку**: могут встречаться редкие и спорные слова. Некоторые грамматические омонимы разрешены сознательно.
2. Необходимо проверить лицензию **самих словарных данных** и атрибуцию их источников; лицензия Python-пакета не обязательно распространяется на весь исходный корпус.
3. Уточнить политику буквы Ё (источник может содержать написания с Е вместо Ё).
4. Отобрать интересные пары и проверить не только концы, но и **все обязательные промежуточные слова**.
5. Создать офлайн-каталог уровней и оценку сложности после очистки.
6. `random_level` пока выбирает пары эвристически, а не равномерно среди всех допустимых пар.
